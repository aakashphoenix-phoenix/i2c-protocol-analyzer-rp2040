7. What the bytes mean

Target 0x3C: OLED (SSD1306) (configured)
Decoded from these bytes: OLED Data Write: 16 bytes
Control byte 0x40: D/C# = 1 → 16 byte(s) of display RAM data (each byte = 8 vertical pixels of one column)
SSD1306 on I2C is write-only: the controller only ever writes it
